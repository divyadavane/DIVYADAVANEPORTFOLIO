## 🌐 Web Portfolio Architecture

This portfolio website is engineered with:
- **Framework**: Next.js 16 (App Router) + React 19 + TypeScript
- **Styling**: Tailwind CSS, Custom Shaders, 3D Glassmorphism & Micro-animations
- **Animations**: Framer Motion, GSAP, Canvas Shaders
- **Icons**: Lucide React
- **Forms**: Web3Forms API Integration

```bash
# Clone the repository
git clone https://github.com/divyadavane/DIVYADAVANEPORTFOLIO.git

# Navigate into directory
cd DIVYADAVANEPORTFOLIO

# Install dependencies
npm install

# Start local development server
npm run dev
```
